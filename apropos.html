À propos

Ce site est un exercice pratique : créer un site web statique et l'héberger avec Nginx dans Docker.

Architecture

  1. Les fichiers HTML/CSS sont copiés dans l'image Docker.
  2. Nginx sert ces fichiers depuis /usr/share/nginx/html.
  3. Le port 80 du conteneur est exposé sur le port 8080 de la machine.

Commandes clés

docker build -t mon-site .
docker run -d --name mon-site -p 8080:80 mon-site
